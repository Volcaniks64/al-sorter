# Azur Lane Character Sorter

A character sorting tool for Azur Lane.

Choose between two characters at a time to determine your preferences and
create a personalized ranking of the Azur Lane roster.

## Features

- Character sorting using head-to-head comparisons
- Faction filtering
- Rarity filtering
- Ship type filtering
- Roster options for:
  - Retrofits
  - Alternate versions
  - Bulins
  - Unplayable characters
  - Sirens
  - Humans
- Save and load sorting progress
- Generate a ranked text list
- Generate a result image
- Generate a shareable result URL
